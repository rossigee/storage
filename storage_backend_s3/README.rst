Configuration
=============

To configure an S3 backend:

#. Go to *Storage > Storage Backends*
#. Create a new backend
#. Set Type to "Amazon S3"
#. Fill in the required fields:

   * **Bucket**: Your S3 bucket name
   * **Access Key ID**: Your AWS access key
   * **Secret Access Key**: Your AWS secret key
   * **Region**: Select the appropriate AWS region

For S3-compatible services (like MinIO, Exoscale, etc.), set the **AWS Host** field
to your custom endpoint URL.
