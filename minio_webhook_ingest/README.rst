Configuration
=============

Configuration is done via ``ir.config_parameter``:

* ``minio_webhook.allowed_ips``: comma-separated list of allowed source IPs
* ``minio_webhook.secret``: optional HMAC-SHA256 secret for signature validation
* ``minio_webhook.minio_endpoint``: MinIO server endpoint
* ``minio_webhook.minio_access_key`` / ``minio_webhook.minio_secret_key``
* ``minio_webhook.minio_secure``: use HTTPS (default true)
* ``minio_webhook.minio_bucket``: bucket name
