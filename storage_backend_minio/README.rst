This module adds MinIO storage backend support to the ``storage_backend`` module.

MinIO is an S3-compatible object storage server that is lightweight and easy to deploy.
This module uses the official ``minio`` Python library which provides a cleaner, more
lightweight alternative to boto3.

Configuration
=============

To configure a MinIO backend:

#. Go to *Storage > Storage Backends*
#. Create a new backend
#. Set Type to "MinIO"
#. Fill in the required fields:

   * **MinIO Host**: Your MinIO server (e.g., localhost:9000)
   * **Bucket**: Your MinIO bucket name
   * **Access Key**: Your MinIO access key
   * **Secret Key**: Your MinIO secret key
   * **Use SSL/TLS**: Enable for production deployments (recommended)
